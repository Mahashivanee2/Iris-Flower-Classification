# Iris-Flower-Classification

A beginner level machine learning project to try and experiment with KNN vs Decision Tree vs Logistic Regression 

I built this using Python in Google Colab

## Dataset

The Iris dataset contains 150 samples belonging to three species:

Iris Setosa

Iris Versicolor

Iris Virginica

Each sample has four features:

Sepal length

Sepal width

Petal length

Petal width

The dataset is already available in Scikit-learn

## Machine Learning Algorithms
I experimented with three classification algorithms:

- K-Nearest Neighbors (KNN)
- Decision Tree Classifier
- Logistic Regression

I also experimented with different K values for KNN using 5-fold cross-validation.

## Results
On my original train-test split, all three models achieved 93.33% accuracy.
